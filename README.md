## 🌟 Key Capabilities & Features

1. **3-Angle FaceNet Biometric Capture**:
   - Automated multi-angle enrollment (Center, Left Tilt, Right Tilt).
   - Real-time blur detection and quality scoring (e.g. `98.5% Sharp`) with retry options.
   - 512-dimensional L2-normalized biometric embeddings synthesized locally and securely synced to Supabase Cloud.

2. **Smart Student ID Auto-Slash Formatter**:
   - Intelligently formats student registration codes (e.g., `ITBSC/2023/EA/WE/037`) on-the-fly.
   - Built-in automatic capitalization and smart backspacing logic.

3. **Cloud Synchronization**:
   - Direct real-time link to Supabase PostgreSQL database for student registration and lecture timetables.

4. **Biometric Privacy Compliant**:
   - Raw facial photos are processed on-device and converted into mathematical vector embeddings; raw images are never exposed to insecure networks.

## 📲 How to Install on Android

1. Download **`Presence_AI.apk`** using the download button above.
2. Open the downloaded `.apk` file on your Android smartphone or tablet.
3. If prompted by Android Security, tap **Settings** and allow **"Install unknown apps"** for your browser/file manager.
4. Tap **Install** and open **Presence AI**.
5. Grant camera permission when prompted to enable real-time biometric face enrollment.
